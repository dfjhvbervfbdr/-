# CyberShield — Защита информации

Учебный адаптивный сайт об основах кибербезопасности. Интерфейс написан на HTML, CSS и Vanilla JavaScript; Express на Node.js раздаёт сайт и небольшой маршрут проверки состояния сервера.

## Возможности

- Главная страница с частыми киберугрозами и наглядной схемой VPN.
- Семь тем с учебными материалами, примерами и пояснениями.
- Тест из десяти вопросов с объяснением ответа и повторным прохождением.
- Последний результат теста сохраняется в `localStorage` текущего браузера и не отправляется на сервер.
- Адаптивное меню, управление с клавиатуры, сокращённые анимации при `prefers-reduced-motion`.
- Базовые HTTP-заголовки безопасности и собственная страница 404.

## Требования

- Node.js 18 или новее.
- npm (устанавливается вместе с Node.js).

## Запуск на Windows через VS Code

1. Установите актуальную LTS-версию Node.js с [официального сайта](https://nodejs.org/). При установке оставьте включённым добавление Node.js в `PATH`.
2. Откройте VS Code. Выберите **File → Open Folder…** и укажите папку проекта `впн сайт` (или `cybershield`, если вы создали проект отдельно).
3. Откройте встроенный терминал через **Terminal → New Terminal**.
4. Убедитесь, что терминал открыт в папке, где лежит `package.json`. Если нет, перейдите туда командой `cd "путь-к-папке"`.
5. Установите зависимости:

   ```powershell
   npm install
   ```

6. Запустите сайт:

   ```powershell
   npm start
   ```

7. Откройте в браузере [http://localhost:3000](http://localhost:3000). Остановить сервер можно сочетанием `Ctrl+C` в терминале.
8. Проверьте навигацию, ссылки на обучение, открытие и закрытие материалов, прохождение всех десяти вопросов и сохранение последнего результата. Для проверки мобильного вида сузьте окно браузера или используйте режим устройства в инструментах разработчика.

## Публикация на GitHub

1. Создайте новый пустой репозиторий на [GitHub](https://github.com/). Не добавляйте туда отдельный README, если он уже есть в этой папке.
2. Откройте терминал VS Code в корне проекта и выполните:

   ```powershell
   git init
   git add .
   git commit -m "Create CyberShield learning site"
   git branch -M main
   git remote add origin https://github.com/ВАШ-АККАУНТ/ВАШ-РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

   Подставьте адрес своего репозитория вместо примера. Файл `.gitignore` исключает `node_modules` и локальные секреты.

## Публикация на Render Free

1. Создайте аккаунт на [Render](https://render.com/) и подключите свой GitHub.
2. В панели Render выберите **New → Web Service**, затем укажите репозиторий CyberShield.
3. Для сервиса выберите бесплатный план **Free**.
4. Укажите команды:
   - **Build Command:** `npm ci`
   - **Start Command:** `npm start`
5. В **Environment Variables** добавьте `NODE_ENV` со значением `production`.
6. Создайте Web Service и дождитесь успешного завершения сборки. Render выдаст публичный адрес вида `https://имя-сервиса.onrender.com`.
7. Откройте публичный адрес и проверьте главную, `/learning`, `/quiz`, неизвестный URL и тест на телефоне.

В репозитории должен быть `package-lock.json`: он фиксирует разрешённые версии зависимостей для воспроизводимой установки через `npm ci`. После изменения зависимостей обновите lock-файл командой `npm install` и отправьте оба файла в GitHub.

## VPN и хранение данных

Render Free публикует сайт в общедоступном интернете и не обеспечивает доступ только через собственный WireGuard VPN. Для настоящего VPN-only доступа потребуется отдельный сервер с WireGuard и настроенными правилами входящего трафика. VPN-схема на сайте — учебная иллюстрация, проверка подключения не выполняется.

Результат теста остаётся в `localStorage` браузера. Он не синхронизируется между устройствами и может быть удалён очисткой данных браузера. Сервер не записывает ответы пользователей и не использует файловую систему Render для постоянного хранения данных.

На бесплатном веб-сервисе Render приложение может засыпать после периода без запросов и медленнее отвечать на первое последующее открытие. Данные, записанные самим приложением в файловую систему сервиса, не являются постоянными.
